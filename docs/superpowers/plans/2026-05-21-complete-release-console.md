# Complete Release Console Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Complete every item in `omd-release-console-improvement-plan.md`, evolving OMD Release Console from a release preparation assistant into the single safe, traceable, resumable release cockpit.

**Architecture:** Keep Rust as the release core and expose fixed, whitelisted capabilities through CLI, HTTP API, and Tauri commands. Split the current monolithic `src/main.rs` only when a task needs a new boundary; otherwise make surgical changes and keep all behavior testable through CLI/API smoke tests. The UI remains the current static Web UI inside Tauri until the release workflow is complete; visual polish is last.

**Tech Stack:** Rust 2021, Tauri v2, serde/serde_json, static HTML/CSS/JavaScript, local JSON state files, macOS `open`, shell commands generated by Rust whitelist only.

---

## File Structure

Current important files:

- `src/main.rs` — current Rust core: CLI, HTTP server, Tauri commands, state manager, release operations.
- `public/index.html` — static UI structure.
- `public/app.js` — release workflow view model, API/Tauri invoke calls, UI rendering.
- `public/styles.css` — release cockpit styling.
- `release.config.json` — non-sensitive release configuration.
- `tauri.conf.json` — desktop shell configuration.
- `package.json` — dev/check/build entry points.
- `.gitignore` — generated/build output ignores.

Planned focused modules after extraction:

- Create `src/state.rs` — owns `ReleaseState`, `ReleaseStep`, checks, artifacts, manifests, suggestions, run metadata, and state-file read/write helpers.
- Create `src/config.rs` — owns `ReleaseConfig`, config validation, and safe public config summary.
- Create `src/actions.rs` — owns fixed action routing, action input validation, and action result shape.
- Create `src/release.rs` — owns release CLI operations: preflight, artifact check, checksums, manifest, verify, publish command generation, report generation.
- Keep `src/main.rs` — binary entrypoint, CLI routing, HTTP routing, Tauri command registration.
- Create `tests/release_state.rs` only if the project is converted to a library; otherwise keep unit tests under `src/main.rs` or extracted module tests.

Do not extract all modules at once. Extract only the module touched by the task being implemented.

```rust
fn check_artifacts(ctx: &CliContext) -> Result<(), String> {
    fs::create_dir_all(&ctx.release_dir).map_err(|error| error.to_string())?;
    ctx.state.start_step("artifactCheck", "检查发布产物")?;
    let artifacts = inspect_artifacts(ctx)?;

    let missing = artifacts
        .iter()
        .filter(|artifact| artifact["required"].as_bool().unwrap_or(false) && !artifact["exists"].as_bool().unwrap_or(false))

    }
    ctx.state.complete_step("artifactCheck", "产物完整", json!({ "count": artifacts.len() }))
}
```

```rust
fn run_safe_release_sequence(ctx: &CliContext, resume_from: &str) -> Result<(), String> {
    let mut active = false;
    for step in release_step_order() {
        if step == resume_from {
            active = true;
        }
        if !active {
            continue;
        }
        match step {
            "preflight" => preflight(ctx)?,
            "check-artifacts" => check_artifacts(ctx)?,
            "manifest" => manifests(ctx)?,
            "verify" => verify(ctx)?,
            "dry-run-release" => {
                let commands = dry_run_commands(ctx)?;
                ctx.state.complete_step("dryRunRelease", "dry-run 发布命令已生成", json!({ "commands": commands }))?;
            }
            "report" => report(ctx)?,
            _ => return Err(format!("未知恢复步骤：{step}")),
        }
    }
    Ok(())
}
```

```rust
fn manifest_platform_diff(github: Option<&Value>, gitee: Option<&Value>) -> Value {
    let github_keys: Vec<String> = github
        .and_then(|value| value["platforms"].as_object())
        .map(|items| items.keys().cloned().collect())
        .unwrap_or_default();
    let gitee_keys: Vec<String> = gitee
        .and_then(|value| value["platforms"].as_object())
        .map(|items| items.keys().cloned().collect())
        .unwrap_or_default();
    json!({
        "missingOnGithub": gitee_keys.iter().filter(|key| !github_keys.contains(key)).cloned().collect::<Vec<_>>(),
        "missingOnGitee": github_keys.iter().filter(|key| !gitee_keys.contains(key)).cloned().collect::<Vec<_>>()
    })
}
```
